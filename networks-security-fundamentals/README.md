# Week 02: Networking Fundamentals & Packet Analysis

This module focuses on Transport Layer (Layer 4) and Application Layer (Layer 7) network primitives, kernel TCP stack state transitions, packet disassembly using `tcpdump`, and network reconnaissance dynamics (`DROP` vs `REJECT`).

---

## 1. Core Networking Invariants

* **TCP 3-Way Handshake Synchronization:**
  * **SYN (`[S]`):** Client issues an Initial Sequence Number ($ISN_{client}$). No application payload is transmitted.
  * **SYN-ACK (`[S.]`):** Server acknowledges by responding with $Ack = ISN_{client} + 1$ and supplies its own $ISN_{server}$.
  * **ACK (`[.]`):** Client completes state transition to `ESTABLISHED` by acknowledging $Ack = ISN_{server} + 1$. Application data transmission can only occur after this transition.

* **Closed Port Kernel Behavior (`RST`):**
  * When a TCP SYN reaches an active network stack on an unlistened port, the operating system kernel immediately generates a `RST-ACK` (`Flags [R.]`) packet with $Win=0$.
  * Port scanners (`nmap -sS`) categorize these ports as `Closed` in sub-millisecond round-trip times.

* **Firewall Dynamics (`REJECT` vs `DROP`):**
  * **`REJECT` (`--reject-with tcp-reset`):** Explicit refusal. The firewall issues an immediate TCP Reset. Scan times remain virtually instant ($<1$ ms).
  * **`DROP` (Blackhole):** Silent packet discard. The client stack enters exponential TCP retransmission and waits until socket timeout ($~2000$ ms).
  * **Product Security Impact:** Utilizing `DROP` at edge security groups maximizes reconnaissance cost and slows down port-scanning adversaries exponentially.

* **Layer 7 Plaintext Vulnerabilities (Sniffing):**
  * Unencrypted protocols (HTTP) transmit Layer 7 headers directly over the TCP payload stream without integrity or confidentiality guarantees.
  * Local actors with `CAP_NET_RAW` or network tap visibility can extract authentication tokens (`Authorization: Bearer`) and API keys passively via BPF filters.
